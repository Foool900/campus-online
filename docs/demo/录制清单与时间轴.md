## 三、录制注意点

- **不要点**「世界观」和地图顶部「EDIT」——目前是占位/未开发，点了会弹「还未开发」。
- 地图是**散点星图**（由地点 id 哈希定位），布局稳定可复现；拖拽平移、滚轮缩放都流畅，可当开场视觉亮点。
- 若想补一个**手机端**镜头：F12 设备模拟切到手机宽度（≤932px），会自动切换为手游 HUD 横屏布局；选竖屏布局还可用小地图按钮切换横/竖。
- 公开任务有「最短完成时长」保护，**现场走「接取→提交→验收」可能被卡时间**；若想现场演示完整任务闭环，用**私密备忘**（无此限制）。
- 夜市「我的摊位 / 店铺竞拍」已预置好卖家与商品；作为小荷，现场做**买家侧**操作（买/盲盒/砍价/竞拍/喇叭）即可。
- 结尾记得补一句项目定位：**本地原型的游戏化校园社交**，不涉及真实地图/校徽/实名/支付。
