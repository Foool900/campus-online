# 演示视频 · 5 分钟脚本与解说词

> 总时长约 5 分钟（300 秒）。每段给【时间】【操作】【口播】。配套字幕见 `字幕-5min.srt`。

## 1. 开场 + 登录（00:00–00:20）

【操作】打开 `http://localhost:5173`，登录框输入 `小荷 / demo1234`，点「登录」。

【口播】大家好，这是 Campus Online——一个校园游戏化社交原型。我先用账号「小荷」登录。

## 2. 地图 + 区域频道（00:20–00:50）

【操作】看双校区星图 → 点「换地图」切到金明 → 点一个地点标记 → 看活动区/聊天区 → 关闭。

【口播】登录进来是一张双校区的校园星图，明伦、金明两个校区，可以拖拽、缩放，一键切换。点开一个地点，就进入它的频道——左边活动区、右边聊天区。

## 3. 世界频道（00:50–01:20）

【操作】底部世界频道输入一条消息，回车发送。

【口播】底部是世界频道，全校实时可见，支持 @ 提及、回复、表情回应。我现场发一条，它是通过 Socket 实时广播的。

## 4. 任务（01:20–01:50）

【操作】打开「任务」页 → 看公开任务与私密备忘 → 点进公开任务详情。

【口播】任务分私密备忘和公开任务。公开任务带金币赏金，发布时赏金先冻结托管；私密备忘完成加经验。

## 5. 成长系统（01:50–02:25）

【操作】「排行」→「成就」→「个人页」→「签到」并现场签到。

【口播】排行榜按经验排名；成就分进度型和隐藏的触发型；个人页汇总等级、金币、徽章；每日签到领金币，连续递增。

## 6. 夜市市场（02:25–03:25）

【操作】打开「市场」，从上到下浏览在售商品、我的摊位、店铺竞拍、纠纷举报、全服喇叭。

【口播】这里是校园夜市。流动地摊抽签抢摊；商品支持普通购买、盲盒、砍价、限时秒杀；固定店铺按周竞拍；还有全服喇叭和纠纷举报。

## 7. 奖池 + 背包 + 虚拟角色（03:25–04:05）

【操作】「奖池」（GACHA）→「背包」→「形象」。

【口播】金币能进奖池抽奖，也能装扮祈愿；物品进背包。重点是这套像素装扮系统——角色由底模加各部位装扮拼出来，可以实时换装。

## 8. 剧情 + 信息大厅 + 好友（04:05–04:45）

【操作】「剧情」→ 剧情详情 → 「Horizon」信息大厅 → 「好友」接受申请。

【口播】剧情把线下打卡搬到线上，打满整章发奖励；右上角 Horizon 是信息大厅；好友支持申请、私聊、群聊。

## 9. 收尾（04:45–05:00）

【操作】回到地图主页。

【口播】以上就是 Campus Online 的全流程——地图、社交、任务、经济、夜市、虚拟角色和剧情。目前是一个本地原型，谢谢观看。
